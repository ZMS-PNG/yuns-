# 3 天开发方案

## Day 1 — 架构与评分闭环

- 完成 PRD、Rubric、架构图。
- 建立 Harness 文件。
- 实现评分权重、等级、JSON Schema。
- 准备 3 条 demo case。

验收：文本输入可以输出 mock 报告。

## Day 2 — ERNIE/OCR/Dify 接入

- 接入 ERNIE API。
- 接入 PaddleOCR 或 OCR API。
- 设计 Dify 节点。
- 增加 JSON 解析失败 fallback。

验收：至少 1 条截图 case 跑通。

## Day 3 — Demo 和交付

- 完成 6 条样例。
- 输出报告样例。
- 整理展示材料。
- 形成 PRD + 架构 + 开发文件夹。

验收：可演示完整流程，且报告具有评分和建议。
