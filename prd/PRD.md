# PRD — 多 Agent 个性化表现评分系统 MVP

## 1. 背景

生活化、娱乐化、智能玩具、沉浸式展陈等场景正在从单轮问答转向多 Agent 角色协作。传统评测关注准确率、任务完成率和工具调用，而本项目关注“是否像角色”“是否有个性表达”“是否能协同合作演绎”。

## 2. 产品目标

在 3 天内完成一个可演示 MVP：输入场景、角色设定、Agent 输出和可选截图，系统自动生成六维评分、总分、等级、评语和改进建议。

## 3. 用户画像

- Agent 产品经理：需要判断角色互动质量。
- 多 Agent 系统开发者：需要定位 Harness、角色边界和协作问题。
- 展陈/玩具/游戏内容团队：需要评估沉浸式互动体验。

## 4. MVP 范围

### 必做

- 文本评测闭环。
- 可选 OCR 上下文输入。
- ERNIE-as-a-Judge Prompt 与 JSON 输出。
- 六维评分与总分计算。
- 报告 JSON 输出。
- 3 类 Demo Case。

### 暂不做

- 大规模 Benchmark。
- 前端 UI。
- 多评委投票。
- 严格 Pearson 校准。
- 复杂版面理解。

## 5. 核心用户流程

1. 用户提供场景描述、角色设定、Agent 输出。
2. 如有截图，系统用 PaddleOCR 提取文字。
3. Context Builder 组装评测输入。
4. ERNIE Judge 按 Rubric 输出结构化评分。
5. Scoring Engine 计算总分和等级。
6. Report Generator 输出报告。

## 6. 成功标准

- 3 个场景类型均能跑通。
- 输出符合 JSON Schema。
- 分数可解释。
- 能明确指出至少 2 条问题和 2 条改进建议。
- 文本模式不依赖 OCR 或外部 Agent API。
